# Ecom Video → Seedance Prompt

这是一个基于deepseek-v4-flash-vision 视觉deepseek大模型的复刻带货爆款视频Skill, 会生成复刻效果的seedance提示词！

> 你刷到一条带货爆款视频，想让 AI 照着再来一条——本 skill 就是那个"翻译官"：
> 它把视频**看懂**（拆成一张张镜头卡片），再把卡片**翻译**成即梦（Seedance）
> 能直接执行的提示词。你拿到手的，是一套可以直接粘贴进即梦的完整提示词包。

**它能回答三个问题：**

1. 这条视频是**怎么拍出来的**？（镜头怎么切、光怎么打、动作怎么排、卖点怎么放）
2. 我要**复刻它**，提示词该**怎么写**？（每镜头一条 + 整片一条 + 负面词 + 参考图清单）
3. 我想**改风格**（自然流种草 / 千川付费流），提示词要**怎么变**？

---

## 一、它是怎么想问题的：先把"感觉"变成"参数"

参考的 6 篇‘点金手丰年’实战方法论文档 反复讲一个核心观点：

> 你写"拍一个好看的视频"，AI 给你一坨废片；你写"25 岁亚洲女性，黑色齐肩长发，
> 缓慢转身，嘴角微微上扬，暖光侧逆光，中景缓慢推镜，4K 高清，面部不变形"——
> 一次出片。**差距不在模型，在提示词。**

方法论把一条好提示词拆成了五个必填项，叫 **S-A-C-S-C**：

| 要素 | 通俗解释 | 例子（头发护理广告） |
|---|---|---|
| **S**ubject 主体 | 画面里是谁/是什么产品，长什么样 | "两位深棕肤色女性，黑色长直发，深灰/米白运动背心" |
| **A**ction 动作 | 在做什么，**按时间顺序一步步写** | "双手伸入→分开头发→向下滑动→滑至发尾" |
| **C**ontext 场景 | 在哪里，光怎么打，有什么细节 | "美发沙龙，镜前柔光侧逆光" |
| **S**hot 镜头 | 景别/视角/景深/运镜 | "特写，平视，浅景深，固定镜头" |
| **C**olor 情绪 | 色调/饱和度/对比度 | "冷色调，高饱和，对比适中" |

五项缺一个，AI 就在那个维度"自由发挥"——而 AI 的自由发挥通常就是翻车现场
（六根手指、脸崩、头发粘成一块）。

**本 skill 做的事，就是让视觉大模型替你完成这套"人肉拆解"**：以前编导要逐帧
看视频、手填分镜表，现在 10 秒视频 16 秒拆完，而且每一步产出都存档、可检查、
可反复用。

## 二、两阶段工作流（先拆解，后生成）

### 阶段一：`analyze.py` —— 把视频拆成"分镜表"（每视频一次，缓存）

```
带货视频
   │ 1fps 抽帧 + ffmpeg 场景切换检测
   ▼
镜头切分（切换点=剪辑点）── 10.1 秒广告 → 切成 4 个镜头
   │ 每镜头取 首/中/尾 关键帧，交给视觉模型
   ▼
镜头卡 × 4（S-A-C-S-C 逐镜头拆解）
   │ 每镜头中间帧 + 全部卡片摘要，再做一次综合分析
   ▼
全局分析（产品/品类/带货框架/自然流还是付费流/钩子/卖点/节奏）
   │
   ▼ storyboard.json（缓存，永不重复拆）
```

**镜头卡长什么样？**（下面是 jimeng 广告镜头 B 的真实拆解，一字未改）

```json
{"shot_type": "特写",
 "angle": "平视，从人物背后拍摄，聚焦于头发",
 "camera_move": "固定镜头",
 "lighting": "冷光柔光，顶光，头发有明显高光",
 "color": "冷色调，高饱和，对比适中",
 "subject_person": "女性，肤色偏深，深灰色运动背心，背对镜头，黑长直发顺滑有光泽",
 "action_steps": ["人物背对镜头，双手从两侧伸入画面，手指分开头发",
                  "手指从头发中段向下滑动，展示顺滑和光泽",
                  "手指继续向下移动，头发在手指间流畅滑过"],
 "interaction": "手指与头发接触，轻轻分开并向下滑动，头发顺滑无打结",
 "onscreen_text": "左上角有 AI生成 水印",
 "selling_point": "头发的顺滑、光泽和健康",
 "purpose": "卖点展示"}
```

注意这些细节：**动作被拆成了带箭头的时序链**（方法论要求"写慢、写连续、写过程"）、
**表情用物理描述**、**水印被如实记录**（后面生成时会作为"不可复刻元素"排除）。
全局分析还会判断：这是美发产品、展示型框架、自然流、钩子是"长发飘逸慢动作"。

### 阶段二：`replicate.py` —— 分镜表 → 提示词包（可反复生成）

```
storyboard.json
   + 风格开关（忠实复刻 / 自然流 / 付费流）
   + 产品补充信息（--product，你比 AI 更懂你卖的东西）
   ▼ 一次推理调用（system = 整套编导规则知识库）
提示词包：
   ① 每镜头提示词（各 ≤200 字，带时间锚点，@参考图占位）
   ② 完整版整段（≤800 字，直接粘贴即梦）
   ③ 负面提示词（中英双语）
   ④ @参考图清单（产品图/人物图怎么拍）
   ⑤ 与原片的差异说明 + 升级建议
   ▼
markdown + 自包含 HTML（每条提示词旁边就摆着原片关键帧，逐镜对照）
```

## 三、实测全程回放（jimeng 商业广告，10.1 秒）

**输入**：`jimeng-2026-06-28-5508-Cinematic commercial featuring identical.mp4`
（834×1112 竖屏，两位深棕肤色女性，甩发+手指梳理长发+运动服造型展示）

**拆解结果**：4 镜头（0-2.6s 双人甩发 / 2.6-4.6s 背影手指梳发特写 /
4.6-7.4s 别墅暖光造型展示 / 7.4-10.1s 互动甩发），全部镜头卡见上节示例。

**忠实复刻版**生成的镜头 A 提示词（真实产出）：

> @人物参考图1 与 @人物参考图2 并排站立，深棕肤色，长黑直发；左侧穿深灰色运动
> 背心和紧身裤，右侧穿米白色运动背心和紧身裤，嘴角微微上扬。缓慢连续动作：
> 自然垂发→左侧甩头，发丝向右飘起→右侧甩头，发丝向左飘起→发缓缓落下。场景：
> 美发沙龙，镜前柔光侧逆光。固定镜头，中景浅景深，冷调高饱和。头发飘逸与空气
> 交互自然，发丝根根分明。人物服装发型一致，五官对称无变形，画面无抖动模糊。

对照着看：原片拆解卡里的每个字段（人物四层、动作时序、光影、景别、色彩）都被
翻译进了提示词，时间锚点从 10 秒等比放大到 15 秒成片，并在差异说明里注明
"AI 水印不复刻"。

**自然流改版**（`--product "假发/接发产品，主打真发质感与牢固自然"`）更能看出
这个 skill 不只是抄：它判断"原片没有促单环节"，于是**自动新增了镜头 E**——
手持假发片的特写促单镜头，负面词也换成了"接口脱离真人头、假发片分界生硬"
这类产品专属约束。这就是方法论说的"学习迁移，不是照搬"。

## 四、快速上手

在你的 codex/workbuddy 等agent，直接下载skill，然后告诉ai 你的deepseek key 则可以 对话使用！

```bash
# 前置：pip install openai；ffmpeg 在 PATH；
#       key 写在 ~/.deepseek_api_key 首行（或环境变量 DEEPSEEK_API_KEY）

# 1. 拆解（每份视频只跑一次，10 秒视频约 16 秒）
python scripts/analyze.py "爆款视频.mp4"

# 2. 生成提示词（三种风格任选，可反复跑）
python scripts/replicate.py "爆款视频.mp4"                          # 忠实复刻
python scripts/replicate.py "爆款视频.mp4" --style organic          # 自然流种草版
python scripts/replicate.py "爆款视频.mp4" --style paid             # 千川付费流版

# 3. 推荐：带上产品信息（AI 只能猜，你说了才算）
python scripts/replicate.py "爆款视频.mp4" --style paid \
       --product "XX品牌精华液，主打烟酰胺美白，蓝色玻璃瓶身"

# 4. 只对某个镜头不满意？单独重出，不动其他镜头
python scripts/replicate.py "爆款视频.mp4" --shot B
```

**参数速查**

| 参数 | 取值 | 说明 |
|---|---|---|
| `--style` | `faithful`（默认）/ `organic` / `paid` | 忠实复刻 / 自然流种草 / 付费流转化 |
| `--product` | 自由文本 | 品牌、卖点、色号等，以此为准覆盖 AI 的猜测 |
| `--duration` | 4-15，默认 15 | 目标成片时长，镜头时间锚点自动等比缩放 |
| `--shot` | 如 `A,C` | 只重出指定镜头 |
| `--out` | 默认 `seedance-out/` | 产出目录 |

产出两个文件：`<视频名>_<风格>_提示词.md`（纯文本，方便复制）和
`<视频名>_<风格>_提示词.html`（**双击浏览器打开**：每条镜头提示词旁边就是原片
关键帧，肉眼核对拆解准不准）。

## 五、三种风格有什么区别

| | faithful 忠实复刻 | organic 自然流 | paid 付费流 |
|---|---|---|---|
| 目标 | 最大程度还原原片 | 抖音自然流种草出单 | 千川投放强转化 |
| 镜头 | 照原片 | 中景跟拍、平视、贴近日常 | 极致特写、视觉冲击 |
| 光影 | 照原片 | 自然光柔光暖色调 | 硬光侧逆光、电影级 |
| 叙事 | 照原片 | 痛点/种草，节奏舒缓 | 奇观钩子、快节奏、行动号召 |
| 会做什么调整 | 只替换不可控元素 | 常会补促单镜头、真实化场景 | 强化钩子、加对比结构 |

## 六、拿到提示词之后怎么用（即梦实操）

1. 按"**@参考图清单**"准备素材：产品图 1-3 张（正面/侧面/细节，自然光+纯色背景
   +抠图锐化）；要用真人脸参考时，照片需打码/抠脸/转手绘风过审
2. 打开即梦网页版 → 视频生成 → **全能参考**模式上传素材
3. 粘贴"**完整版提示词**" + 基础参数段；英文负面词贴到负向栏
4. 场景简单（≤2 分镜）可先用 **Seedance 2.0 fast** 省积分
5. 效果不对 → 用"单变量修改法"：回本 skill 只改一处（换 `--product` 或 `--style`
   或单镜头 `--shot`），别全推重来
6. 建议 720P 出小样验证逻辑，再上 1080P 成片（省一半积分）

## 八、成本账

| 操作 | API 调用 | 耗时（10s 视频实测） |
|---|---|---|
| 拆解 analyze | 镜头数 + 1 次（关推理） | 16 秒 |
| 生成 replicate | 1 次（开推理，max_tokens 32768） | 24-69 秒 |
| 换风格/改产品再生成 | 每版 1 次 | 同上（分镜表直接复用缓存） |
| 单镜头重出 `--shot B` | 1 次 | 更快 |

拆解一次永久缓存；同一条视频出"忠实+自然流+付费流"三版，只花 1 次拆解 + 3 次生成。

## 九、常见问题

**Q：为什么不把视频直接丢给模型要提示词，要分两步？**
一次调用做不到两件事：既要逐镜头看清楚（每镜头单独关键帧分析），又要按编导规则
约束输出（知识库作为 system 注入）。分两步还有个好处——中间产物分镜表可以人工
检查纠错，生成可以局部重跑，而不是每次全凭运气。

**Q：提示词里的品牌名/产品外观靠谱吗？**
AI 只能从画面猜产品。用 `--product` 告诉它真实信息（品牌、卖点、色号），生成会
以此为准；具体产品外观用 `@产品参考图` 占位 + "1:1 还原"约束，不要指望文字描述
还原品牌 LOGO——差异说明里会明确列出哪些元素不可控。

**Q：口播文案是原片原话吗？**
不是。模型没有音频模态，口播内容是从字幕和画面推断的（产出中已标注"推断"）。
准确口播建议自己补：15 秒视频配 120 字左右，正好符合方法论的最佳字数。

**Q：能处理多长的视频？**
拆解按 1fps（>2 分钟自动降 0.5fps），镜头多时拆解调用数=镜头数+1。几分钟的
视频几十秒拆完；超长素材建议先切出要复刻的片段。

**Q：和另外两个 skill 什么关系？**
同一套视觉理解技术的三兄弟：`deepseek-v4-flash-vision-rag` 管 PDF 问答，
`deepseek-v4-flash-vision-video-rag` 管视频问答，本 skill 管带货视频→提示词生产。
密钥机制、API 封装完全一致。

## 十、已知局限

- 无音频分析：口播/BGM 只能从画面推断
- 剧烈动作、多人复杂交互的视频：拆解照常，但生成会按编导规则主动降速降复杂度
  （这是刻意为之——方法论实测这类元素极易翻车，稳定优先）
- OCR 对画面小字（<20px）可靠性一般，只作辅助线索
- 非带货类视频也能拆解生成，但"钩子/促单"等带货字段的建议参考意义有限
